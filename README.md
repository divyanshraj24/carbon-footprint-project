# EcoMind AI - Production-Ready Carbon Footprint Assistant

A complete full-stack AI-powered web application that helps individuals understand, track, predict, and reduce their carbon footprint through personalized recommendations and intelligent decision-making.

## Project Status

🚀 **In Development** - Building the complete EcoMind AI platform

## Tech Stack

### Frontend
- Next.js with React
- TypeScript
- Tailwind CSS
- Shadcn UI components

### Backend
- Node.js with Express
- TypeScript
- PostgreSQL

### AI & ML
- Gemini API for intelligent recommendations
- ML-based carbon forecasting
